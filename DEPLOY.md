# How to deploy

Start by updating the `version` field in manifest.json.

Then run the zip command:
`zip -r archive.zip . -x '*.git*'`

Then go to the [Google webconsole](https://chrome.google.com/webstore/devconsole/31fca0be-2cb8-451d-918b-7fc8715cab96/pmgcnlblbioeammhnochgljnopbagnhp/edit?hl=fr).

And to the [Firefox add-on center](https://addons.mozilla.org/fr/developers/).
